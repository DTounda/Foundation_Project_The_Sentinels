# MediCheck

MediCheck is a proposed mobile application that helps users find medicine information, check whether a medicine matches a registered record, identify possible ingredient allergies, and report products that cannot be confirmed as authentic.

The project is focused on users in Kigali, Rwanda. It is intended to provide information only and does not replace advice from a doctor or pharmacist, laboratory testing, or official regulatory inspections.

## Planned Features

- Search for medicines by name or scan a barcode/QR code.
- Compare listed medicine ingredients with a user's allergy profile.
- Display verification results such as verified, not confirmed, or not found.
- Allow users to report suspicious products through a reporting channel.
